## Dahlia Search Application

This project is a Tkinter-based desktop application for searching and displaying information about dahlias.
The application connects to a SQLite database and allows users to search dahlias by name, color, or number.
The search results are displayed in the application along with images of the dahlias.

## Features

- Search for dahlias by name, color, or number
- Display search results in a user-friendly interface
- Show images of the dahlias alongside their details

Search for dahlias:

Select the search criteria (name, color, or number).

Click the "Search" button to view the results.
