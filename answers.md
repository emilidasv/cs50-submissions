# From the Deep

In this problem, you'll write freeform responses to the questions provided in the specification.

## Random Partitioning

It will be even distributed among the boats, but you need to search among all boats to find it.

## Partitioning by Hour

It will not be even distributed among the boats, but you can easily find it, not need to search all boats.

## Partitioning by Hash Value

It will be even distributed among the boats. You need to search among all the boats to find it. You can find a specific tie by only searching on one boat.
